NEW Windows 11の「AutoPlay」が刷新へ、WinUI 3移行でダークモード対応か
Windows Latestは2026年8月6日（現地時間）、Windows 11の自動再生ダイアログ「AutoPlay」が刷新され、ダークモードに対応する可能性があると伝えた。MicrosoftはWindowsシェルのより多くの部分をWinUI 3へ移行する方針を明らかにしており、AutoPlayもその対象となる。USBメモリーやSDカードを接続した際に表示される古くからのUIも、Windows 11のデザインへと近代化されることになりそうだ。
