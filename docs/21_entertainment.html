NEW Windows 11でメモリを食うアプリを完全終了、便利な「タスクを終了する」の使い方
Windows 11には、タスクバーからアプリを直接強制終了できる「タスクを終了する」機能が用意されている。通常は応答しなくなったアプリを終了する際などに利用する機能だが、閉じるボタンを押してもバックグラウンドで動作し続けるアプリを終了し、メモリを解放する用途にも使える。Windows Latestは9月14日(現地時間)、WhatsApp、Teams、Discordなどを例に、この機能の活用方法を紹介した。

NEW 自動車業界 ニュースの見方 第62回 日産が国内生産を再編! 年産100万台の確立は達成可能なのか
日産自動車は日本国内の生産体制を再編する。ミニバン「エルグランド」「セレナ」の生産を九州工場から栃木工場へと移すなど、生産車種の移管が主な内容だ。国内年産100万台体制の確立を目指す日産だが、はたして達成可能なのか。

NEW コスモ、航空自衛隊ブルーインパルスに国産SAFを供給 - 9月19日の展示飛行で活用
コスモエネルギーホールディングスのグループ会社であるコスモ石油マーケティングはこのほど、愛知県および名古屋市を通じて、国産SAF(Sustainable Aviation Fuel：持続可能な航空燃料)を航空自衛隊「ブルーインパルス」に供給した。

NEW 猫漫画家・邑田の新作コミックエッセイ『だから私は海を打つ』、パチンコ「海物語」とまさかのコラボ
KADOKAWAは、SNSで人気を集める漫画家・邑田の新作コミックエッセイ『だから私は海を打つ』を2026年9月7日(月)に発売する。塩対応な飼い猫・あんちゃん、個性豊かな家族、パチンコ、そして過酷な雪国暮らし──邑田ならではの、日常をシュールなユーモアで描くコミックエッセイ第2弾で、カラー写真ページや紙書籍限定の豪華仕様、50ページ以上の描き下ろしが収録される。
