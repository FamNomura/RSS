NEW Windows 11「低遅延プロファイル」でアプリ起動が高速化、実機検証では7秒→3秒に
Windows Latestは2026年8月12日（現地時間）、Windows 11の「低遅延プロファイル」が一般的なアプリの起動時にも機能するようになったと伝えた。8月のセキュリティ更新プログラム「KB5121003」で強化されたもので、ChromeやPowerPointなど複数のアプリでCPUの動作周波数が大きく上昇することを確認。天気アプリを使った比較動画では、起動時間が約7秒から約3秒に短縮する様子も確認された。
