NEW NICT、チップ上面から光を取り出す深紫外LEDを開発 - WPEは従来比約35％向上

NEW Windows 11 26H2を8GBノートPCで検証、メモリ使用量が5GBから3.3GBに減少
Windows Latestは2026年10月21日(現地時間)、メモリ8GBを搭載したノートPCでWindows 11バージョン26H2の動作を検証した結果を報告した。再起動直後のメモリー使用量は、従来の25H2では5GBだったのに対し、26H2では3.3GBに減少した。ただし、実際のアプリ使用時の性能向上については、引き続き検証が必要としている。
