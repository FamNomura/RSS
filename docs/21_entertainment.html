NEW GitHub大規模障害、原因は「負荷集中」と設定ミス　Copilotにも影響
GitHubが8月17日に発生した大規模障害について根本原因分析(RCA: Root Cause Analysis)を公開した。障害はデータセンターへのトラフィック集中を発端に、自動スケーリングの設定ミスやリトライ処理によって拡大。GitHub.comやActions、Copilotなど広範なサービスに影響し、完全復旧まで7時間47分を要した。

NEW 日清紡マイクロデバイス、実装面積を80％削減する「シリコンマザーボード」技術を確立
日清紡マイクロデバイスは、シリコン基板の両面に回路を形成し、ICと受動部品を一体集約できる3次元実装技術「シリコンマザーボード(Si-MB)」を確立したことを発表した。シリコン基板の内部と両面を活用して多様な部品を集積することで、試作品では従来のディスクリート構成と比べて実装面積を約80％削減したという。

NEW Windows 11、Chromeなどのカメラ・マイクへのアクセスを個別に許可・拒否可能に
Windows 11で、Google ChromeやDiscord、Steamなどのデスクトップアプリについて、カメラやマイクへのアクセスをアプリごとに制御できる新機能が確認された。これまでWin32アプリは一括でしか設定できなかったが、Windows 11ビルド26340.9212では個別設定が可能になっている。Windows Centralが8月19日（米国時間）に伝えた。
