NEW 「来月から営業部に異動です」突然の辞令で社員が孤立…異動先でやってはいけない「NG対応」とは?
「配属ガチャ」という言葉が広がるなか、突然の異動辞令に戸惑った経験はありませんか? 希望していた仕事から離れ、慣れない部署で一から人間関係を築くことに。「新しい職場になじめない」「何を期待されているのかわからない」――そんな異動後の悩みは、本人の適応力だけの問題ではないかもしれません。実は、社員が成長できる職場と、意欲を失ってしまう職場には、異動者の「受け入れ方」に大きな違いがあるといいます。人事・労務の専門家が、異動後につまずく職場の共通点と、会社や上司が見直すべきポイントを解説します。

NEW Windows Updateの証明書が2027年に期限切れ、影響を受けるOSと対処方法
Microsoftは10月8日（現地時間）、Windows Updateへの接続に使用する証明書が2027年5月と6月に有効期限を迎えるとして、Windowsのバージョン別に必要な対応を公開した。新しい証明書が導入されていない端末では、期限切れ後にWindows Updateへ接続できなくなり、セキュリティ更新プログラムなどを受信できなくなる恐れがある。同社は、企業のIT管理者に対して、利用中のWindowsのバージョンと更新状況を確認し、期限までに必要な対策を実施するよう呼びかけている。

NEW Windows 11のスタートメニューは廃止すべき？ Microsoft幹部が見解

NEW 息子3人を育て、25年の結婚生活を経て離婚した53歳女性　元夫とは良好な関係、でも新たな恋は難しく“ギリギリの変わった方”を選びがちで…YOU「これは私が書いたおハガキでしょうか?」

NEW ガソリンスタンドの人手不足をAIで解決? コスモの新システムを取材
ガソリンスタンドの人手不足が深刻化し、営業時間の短縮や閉店を余儀なくされる店舗が増えている。そこでコスモ石油が導入を進めているのが、AIによる自動給油許可監視システム「AiQ PERMISSION」だ。どんな仕組みなのか、導入店舗で取材した。
